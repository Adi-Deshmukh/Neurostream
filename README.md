# NeuroStream

Intro-only scaffold for a two-phase streaming SNN project with prototype memory and drift adaptation.

## Current Status

This repository is intentionally initialized with structure and file stubs only.
No training, model, data, or evaluation implementation code has been added yet.

## Planned Flow

- Phase A: Supervised SNN feature learning and freezing.
- Phase B: Streaming adaptation with EMA prototypes and pseudo-labels.
- Sleep consolidation: Replay and cosine-anchor stabilization.

## Notes

Use this scaffold as the starting point for implementation, experiments, and reproducible sweeps.
